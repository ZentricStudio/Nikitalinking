# Example command

This file becomes the `/example` slash command for everyone with the marketplace installed.

To make your own command, copy this file to `commands/<your-name>.md`, edit the
`description` in the frontmatter, and write the instructions below. The filename
(without `.md`) becomes the command name.

When run, respond with a short confirmation that the shared command system works,
then do whatever the command is supposed to do.

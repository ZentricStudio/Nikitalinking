# People

Each person who links into the hub gets a small folder here. Use it for notes,
machine lists, or personal skills-in-progress before you promote them to the
shared library.

| Person | Folder |
|--------|--------|
| ZentricStudio (owner) | `zentric/` |
| Sam | `sam/` |
| Sam's uncle | `sams-uncle/` |

To add a new person: create `people/<their-name>/`, add them as a repo
collaborator (see `docs/LINKING.md`), and add a row to this table and the one in
the top-level `README.md`.
